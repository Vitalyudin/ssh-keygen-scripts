Simple ssh keygen scripts in Powershell for Windows and bash for MacOS and Linux systems. 

Generate a key and store it in the default ~/.ssh/config file.

Run it without parameters to get help:
```
$ bash keygen.sh
How to use: keygen.sh <domain> [key_name] [username]
<...> - required
[...] - optional
```
